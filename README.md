## Descripción

Este repositorio reúne la solución del **Taller 3**, compuesto por **20 ejercicios prácticos**: 10 en JavaScript y 10 en TypeScript. Cada archivo contiene el enunciado del ejercicio como comentario al inicio, seguido de su solución.

**JavaScript**: variables, funciones, estructuras de control (`switch`, `for`), arreglos y sus métodos (`push`, `unshift`, `pop`, `filter`, `map`, `find`, `reduce`), objetos, `Object.entries()`, desestructuración y operador *spread*.

**TypeScript**: tipos básicos, arreglos tipados, `type`, `interface`, *union types*, `enum`, clases, herencia, *generics* y un ejercicio integrador de gestión de usuarios.
