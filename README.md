# Taller 3 - JavaScript / TypeScript

Repositorio del **Taller 3** de la asignatura **Programación en Ambiente Web I**, Facultad de Ingeniería, Unidad Central del Valle del Cauca (UCEVA).

**Docente:** Jesus David Mejia Vergara

## Descripción

Este taller pone en práctica los conceptos fundamentales de JavaScript y TypeScript vistos durante el curso: variables, funciones, estructuras de control, arreglos, objetos, métodos, desestructuración, operador spread y manipulación de datos en JavaScript; y tipos básicos, arrays, types, interfaces, union types, enums, clases, herencia, generics y utility types en TypeScript.
